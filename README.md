## Cómo correr un programa

Abre una terminal **dentro de esta carpeta** y escribe el comando:

```bash
# Mac
python3 0_verificar.py

# Windows
py 0_verificar.py
```

Para los demos, el comando incluye la carpeta, por ejemplo:

```bash
# Mac
python3 demo1_portero/portero.py

# Windows
py demo1_portero/portero.py
```

Sin terminal: abre el archivo con IDLE (viene con Python) y presiona F5.

## Cómo cambiar una PERILLA

1. Abre el archivo del demo con un editor (VS Code, IDLE o Bloc de notas).
2. Busca la línea que está debajo del comentario `PERILLA`.
3. Cambia solo lo que dice el comentario (por ejemplo `False` por `True`).
4. Guarda (Ctrl+S en Windows, Cmd+S en Mac) y vuelve a correr el programa.
